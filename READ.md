# Objetivo

O objetivo deste material é desenvolver os conhecimentos necessários para a criação de aplicativos utilizando Python, desde os fundamentos da programação até o desenvolvimento de aplicações mais estruturadas.

Durante a unidade curricular serão trabalhados conceitos de programação, organização de código, estruturas de dados, funções, orientação a objetos e desenvolvimento de aplicações.

# Ambiente de Desenvolvimento

Os projetos utilizam a linguagem **Python**.

O ambiente de desenvolvimento principal utilizado neste material é o **PyCharm**.

Também podem ser utilizados outros ambientes e editores compatíveis com Python.

# Como Estudar

Para cada conteúdo, recomenda-se seguir a sequência:

1. Estudar o conceito
2. Analisar os exemplos
3. Executar os programas
4. Alterar os exemplos
5. Testar diferentes situações
6. Resolver os exercícios
7. Desenvolver os desafios
8. Aplicar os conhecimentos nos projetos

O objetivo é compreender o funcionamento do código e desenvolver autonomia para criar novas soluções.

# Boas Práticas de Programação

Durante o desenvolvimento dos aplicativos, procure:

* Utilizar nomes de variáveis claros
* Organizar o código
* Evitar repetição desnecessária
* Criar funções para organizar funcionalidades
* Utilizar comentários quando necessário
* Validar os dados recebidos
* Tratar possíveis erros
* Testar diferentes situações
* Manter os arquivos organizados
* Utilizar boas práticas de programação

# Objetivo Final

Ao final da unidade curricular, espera-se que o aluno seja capaz de desenvolver aplicações utilizando Python, aplicando conceitos de programação, organização de código, estruturas de dados, funções, orientação a objetos e integração com outros recursos.

O foco não está apenas em aprender a linguagem Python, mas em **desenvolver a capacidade de analisar problemas, elaborar soluções e transformá-las em aplicações funcionais**.
